# minecraft-cards-bot

A Discord bot that checks shops hourly for Minecraft sticker card availability and notifies users
about the cards they are missing.

See `docs/` for the design and implementation plan.

## Development

All tasks run through the vendored Mise launcher:

```bash
./bin/mise run install
./bin/mise run dev
./bin/mise run test
```
